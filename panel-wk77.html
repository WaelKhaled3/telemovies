إدارة المشاهدة

فعّل المشاهدة واختر العمل لإدارة أجزائه أو مواسمه وحلقاته وسيرفراته. هذه الروابط تُعرض كتضمين عادي فقط إذا سمح المصدر بذلك؛ لا يجري تجاوز قيود أي خدمة.

معاينة صفحة العمل

احفظ هنا، ثم استخدم «حفظ ونشر» لنشر البيانات. أنواع المصادر: تلقائي، MP4، HLS/M3U8، iframe، YouTube، VK، OK.ru أو صفحة HTML لمشغل خارجي.

إعداد زر المشاهدة

بعد حفظ العمل، أضف روابط الأجزاء أو الحلقات من تبويب «إدارة المشاهدة». لن يظهر الزر إلا إذا فعّلت خيار ظهوره.

أزرار إضافية مخصصة

اكتب اسم الزر والرابط واختر لونه. مثال: رابط الجزء الثاني، قناة الترجمة، مشاهدة الإعلان.

تغيير كلمة المرور

اكتب كلمة مرور جديدة (12 حرفاً فأكثر) ليظهر لك سطر تضعه مكان السطر const ADMIN_HASH في ملف اللوحة على GitHub.

استيراد وتصدير البيانات

نزّل الملف بعد التعديل وارفعه إلى GitHub باسم films.json مع استبدال الملف القديم.
